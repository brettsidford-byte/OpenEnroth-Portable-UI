# OpenEnroth Portable UI 1.1.1

## Fixes

- Prevent duplicate controller messages in one menu update from immediately confirming Quit or New Game.
- Retain the safe multi-page Gamepad Controls rendering fix for actions without a current binding.
- Keep Gamepad Controls action labels limited to ten characters.
- Use the dedicated Prev and Next artwork without duplicate text drawn over it.

## Native-resolution UI replacements

- Rebuild all five character-screen buttons in clearly differentiated released and pressed states.
- Replace the character Exit pair, spellbook Close pair, and all three alignment variants of the commonly shared Close strip.
- Replace all four bottom-right HUD controls: Cast Spell, Rest, Quick Reference and Options.
- Provide distinct Neutral/A, Good/B and Evil/C HUD palettes while preserving the exact dimensions of every original slot.

All replacement images are bundled with OpenEnroth Portable UI. Users' original Might & Magic VII archives are not modified.
