# OpenEnroth Portable UI 1.1.2

## Fixes

- Draw the four remastered bottom-right HUD controls continuously over the original alignment frame.
- Prevent ordinary branchless NPC greetings from opening Android's soft keyboard.
- Restore the missing released-state Portable PNGs for dialogue confirmation controls.
- Draw a dedicated Portable Exit control over the Quick Reference screen's original embedded button.
- Update the Android release workflow's artifact and compiler-cache actions to Node.js 24-compatible releases.

## Remastered controls

- Rebuild Save, Load and Cancel in matching released and pressed states.
- Rebuild the character Stats, Skills, Inventory, Awards and Exit controls in matching released and pressed states.
- Refresh compact OK, Cancel and Exit confirmation controls in the same visual style.

All replacements retain their native pixel dimensions and are bundled with OpenEnroth Portable UI. Users' original Might & Magic VII archives are not modified.
