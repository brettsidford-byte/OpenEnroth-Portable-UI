# OpenEnroth Portable UI 1.1.4

## Fixes

- Restore Android screen-aware face-button mapping so gameplay actions reused by menus do not fire together, including the Jump and Open Inventory overlap.
- Restore the missing gamepad configuration entries for Toggle Mouse Look and all four Arcomage actions, so the Gamepad Controls pages show usable bindings instead of `INVALID`.
- Draw the Portable Current Quests, Auto Notes, Map, Spellbook Close and Rest controls on the final visible UI layer so stock artwork cannot cover them.
- Align the main-menu Load replacement with its actual button rectangle, matching the correctly positioned Cancel control.
- Preserve the Portable character-screen, Save/Load, shared Exit/Close, HUD and earlier gamepad fixes from versions 1.1.1 through 1.1.3.

Portable PNG replacements remain separate from users' original Might & Magic VII archives.
