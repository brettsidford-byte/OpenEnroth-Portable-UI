# OpenEnroth Portable UI 1.1.5

## Fixes

- Fix the startup crash introduced in 1.1.4 by giving the RG405V gamepad Select input a unique serialized name instead of colliding with the existing keyboard Select key.
- Keep the independent RG405V Select and dedicated Back mappings introduced in 1.1.4.
- Preserve the Portable UI artwork, screen layering, button placement and context-aware gamepad fixes from earlier releases.

No application-data reset or replacement of users' original Might & Magic VII archives is required.
