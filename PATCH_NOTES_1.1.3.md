# OpenEnroth Portable UI 1.1.3

## Fixes

- Draw all five Portable character-screen controls after the original character UI and paper doll so baked-in controls cannot cover them.
- Keep the active character tab's pressed state on the final rendering layer.
- Draw the Portable Save, Load and Cancel controls above the original backgrounds in both in-game and main-menu modes.
- Align Save/Load Cancel and transition confirmation controls with their actual button rectangles.
- Preserve all Portable UI fixes and remastered assets included in version 1.1.2.

The replacement PNGs remain separate from users' original Might & Magic VII archives.
